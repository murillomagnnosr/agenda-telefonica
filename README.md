Este projeto foi desenvolvido como parte da disciplina de Estruturas de Dados, com o objetivo de praticar o uso de listas em Python (conceito equivalente ao ArrayList).

A aplicação consiste em uma lista telefônica simples, permitindo o gerenciamento básico de contatos e reforçando conceitos fundamentais aprendidos em sala de aula.


O principal objetivo deste projeto é consolidar os conhecimentos sobre:

Estruturas de dados do tipo lista
Inserção e remoção de elementos
Busca de informações em uma lista
Uso de estruturas de repetição (loops)
Uso de estruturas condicionais
Organização básica de código

O sistema possui as seguintes funcionalidades:

Adicionar um novo contato
Listar todos os contatos cadastrados
Buscar um contato pelo nome
Remover um contato da lista
Conceitos Aplicados

Durante o desenvolvimento, foram aplicados os seguintes conceitos:

Manipulação de listas em Python
Estrutura de dados dinâmica (crescimento da lista)
Percurso de listas (iterações)
Comparação de dados (busca por nome)
Organização lógica de funções
